\section{Objetivos da pesquisa}
\label{sec:objetivos-da-pesquisa}

Esta seção engloba os propósitos da investigação, abrangendo tanto o objetivo principal quanto as ações necessárias para alcançar esse objetivo (objetivo específicas).

\subsection{Objetivo geral}
\label{subsec:objetivo-geral}
Neste trabalho, apresentamos os conceitos do \ac*{gpr}, suas propriedades elétricas, a caracterização do sistema de radar, modelagem direta, processamento e  interpretação dos dados.

\subsection{Objetivos específicos}
\label{subsec:objetivos-especificos}
Entre os objetivos específicos buscados no estudo podem ser citados:
\begin{itemize}
    \item Detalhar as etapas de processamentos de dados de \ac*{gpr};
    \item Realizar um processamento de um dado real de \ac*{gpr}, usando software \ac{gprpy};
    \item Realizar simulações de modelagem direta usando software \ac{gprpy};
    \item Aplicação do \ac{gpr} em diferentes dados sintéticos com ruído;
    \item Aplicação e comparação do \ac*{gpr} em dados reais;
\end{itemize}
